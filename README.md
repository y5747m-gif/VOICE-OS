# VOICE OS

**Your Phone. Your Voice. Your Intelligence.**

واجهة صوتية أصلية لـ Android. اكتب أو قول أمرًا بالمصري أو بالإنجليزي؛ VOICE OS يطابقه بإجراء مسموح، يطلبه من Android، ويعرض النتيجة الفعلية. ده **تطبيق Android عادي**، مش روم أو Launcher بديل، ومش واجهة دردشة بتتخيّل التنفيذ.

## الموجود في 0.2.0

- **Home** بتصميم داكن/فاتح وواجهة RTL، وOrb متحرك يستجيب لمستوى الصوت الحقيقي لما خدمة التعرّف تبعته.
- مايك بالضغط فقط باستخدام `SpeechRecognizer`. النص الجزئي ظاهر لكنه **مش مدخل للتنفيذ**. الكتابة والاختصارات تشتغل من غير إذن الميكروفون.
- واجهة **Assistant** وسجل للجلسة ونطق للنتيجة بصوت محلي من `TextToSpeech` لو مثبت. ممكن إعادة سماع الرد أو إيقاف الاستماع/التنفيذ قبل تسليم الطلب.
- **14 إجراء**: فتح واتساب ويوتيوب وإنستجرام وفيسبوك وSpotify وخرائط جوجل (حسب التثبيت)، والكاميرا ولوحة الاتصال، وإعدادات النظام وWi‑Fi وBluetooth والموقع والشاشة، وقراءة نسبة البطارية.
- اختيار حتى ثلاثة اختصارات يدوية، اسم ترحيب اختياري مشفّر بمفتاح من Android Keystore، وسجل Room اختياري **لبيانات النتيجة فقط**. النص الأصلي والصوت لا يكتبان في قاعدة البيانات.

نسخة Android الأصلية تستخدم قواعد محلية محدودة وليست نموذجًا لغويًا؛ تكامل Groq الاختياري موجود في نسخة الويب فقط ولا يتحكم في إجراءات Android. طلب «افتح واتساب وابعت لمحمد» لا يفتح التطبيق ولا يرسل شيئًا؛ المحرك يرفض الطلب كله. فتح لوحة الاتصال لا يبدأ مكالمة، وفتح تطبيق وسائط لا يبدأ تشغيل محتواه. نتيجة فتح التطبيق تعني أن `startActivity` لم يرجع خطأ، ولا تعني أن التطبيق الآخر نفّذ مهمة.

## التثبيت من الموبايل

- **تطبيق الموقع (Android وiPhone):** افتح موقع VOICE OS عبر HTTPS، واضغط **ثبّت التطبيق** أو أضفه للشاشة الرئيسية من قائمة المتصفح. التحديثات تيجي من نفس الموقع.
- **تطبيق Android الأصلي:** بعد نشر APK موقّع، نزّله من نفس الموقع. افتح **الإعدادات ← الموقع والتحديثات** في التطبيق، واحفظ عنوان الموقع الآمن، ثم افحص إصدار أحدث. التنزيل يتم من المتصفح والتثبيت بموافقتك في Android. الربط لا يرفع سجل الأوامر أو الصوت، وميزات التطبيق المحلية تشتغل من غيره.

المعاينة الحالية للويب؛ لا يوجد APK نهائي منشور. راجع [خطوات الاستضافة والتوقيع والتوزيع](web/README.md#نشر-apk-وربطه-بالموقع).

## البناء والتشغيل

**المتطلبات:** Android Studio يدعم AGP 8.11، **JDK 17**، تطبيق يستهدف **SDK 36**، وجهاز أو محاكي **API 26+**. اضبط Gradle JDK على JDK 17، وثبّت من SDK Manager: `Android SDK Platform 36`، و`Build-Tools 35.0.0`، و`Platform-Tools`. يحتاج أول Sync إلى Gradle Distributions وGoogle Maven وMaven Central. الوظائف المحلية لا تحتاج مفتاح API أو Backend؛ عنوان HTTPS مطلوب فقط لو عايز تربط الموقع وتفحص إصدار APK.

1. افتح جذر المستودع في Android Studio واعمل **Gradle Sync**. Android Studio يحدد `sdk.dir` محليًا؛ من الطرفية اضبط `ANDROID_HOME` أو `local.properties` ليشير إلى الـ SDK.
2. اختر Run configuration **app** وشغّلها على جهازك. أو من الطرفية:

```bash
./gradlew :core:test :app:lintDebug :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

على Windows استخدم `gradlew.bat` بدل `./gradlew`. مهمة `assembleDebug` تنتج APK للتطوير، مش APK إصدار نهائي موقّع للنشر.

3. من **المساعد** اكتب `البطارية كام؟` أو `افتح إعدادات الواي فاي`. جرّب الكتابة الأول لتفصل اختبار التنفيذ عن توفر مزوّد الصوت.
4. جرّب الميكروفون من الرئيسية واسمح بالإذن عند طلبه. الوضع الافتراضي **تعرّف على الجهاز**: يحتاج Android 12+ وخدمة محلية تدعم اللغة `ar-EG` أو `en-US`. لو مش متاحة، استخدم الكتابة أو فعّل **مزوّد التعرّف في أندرويد** من الإعدادات بعد قراءة الموافقة: المزوّد قد يعالج الصوت على الإنترنت. مفيش انتقال تلقائي للمزوّد ده. توفر نطق الردود مستقل عن توفر التعرّف.

### الاختبارات

```bash
python3 scripts/check-resources.py
./gradlew :core:test :app:lintDebug :app:assembleDebugAndroidTest
# مع هاتف أو محاكٍ شغّال واتصال adb (يفضّل تثبيت Debug جديد):
./gradlew :app:connectedDebugAndroidTest
```

لفحص منطق الأوامر على Linux بدون Android SDK أو تنزيل Gradle، استخدم `scripts/check-core.sh` مع `kotlinc` 2.1.x وJava 17 ونسخة الـ compiler التي تتضمّن `kotlinx-coroutines-core-jvm.jar`. استخدم `KOTLINC` أو `KOTLIN_LIB` لو المسار مش تلقائي. ملف CI يبني النسخة التجريبية ويضيف مسار تشغيل للاختبارات على محاكي عند الطلب؛ راجع [سجل التحقق](docs/TESTING.md) لمعرفة الفرق بين الاختبارات الجاهزة وما تم تشغيله هنا.

## بنية المشروع

```text
core/                          Kotlin/JVM: قواعد اللغة، أنواع الأوامر، عقد التنفيذ
app/src/main/java/ai/voiceos/
  ui/                          Compose، Material 3، Orb، RTL والشاشات
  voice/                       SpeechRecognizer وTextToSpeech
  ai/                          MVVM وحالة جلسة الأمر ورسائل النتائج
  actions/                     محوّل Android Intents وBatteryManager
  data/                        Room لسجل النتائج المنظّم
  memory/                      تخزين اسم الترحيب بـ Android Keystore
  permissions/                 إذن الميكروفون والانتقال لإعدادات Android
  settings/                    التفضيلات المحلية ولغة الواجهة
  site/                        اتصال HTTPS اختياري لقراءة بيانات إصدار Android
web/                           React PWA وخادم الصوت وتوزيع APK الموقّع
```
